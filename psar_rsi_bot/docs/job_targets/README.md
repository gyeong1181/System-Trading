# Job Targets 기록 운영 규칙

## 파일 네이밍 규칙
- `YYYY-MM-DD_company_role.md`
- 예: `2026-01-14_GSNeotek_SA-Cloud.md`

## 필수 템플릿 섹션
- 회사/포지션
- 지원일 / 채용 링크 / 채널 / 상태
- JD 핵심 요구사항 요약 (담당업무/자격/우대 5줄)
- 내 매칭 포인트 (프로젝트 근거 bullet 5개)
- 제출물 체크리스트 (이력서/자소서/포폴/증거 스냅샷)
- 자소서 초안 링크/버전 (로컬 경로만)
- 면접 대비 예상질문 10개
- 결과/피드백 (빈칸 유지)
- 다음번 개선점 (빈칸 유지)

## 민감정보 금지
- 이메일/전화/주소/주민번호/계정키/연봉 등 금지
- 필요 시 마스킹 (예: ***@***.com)

## 작성 규칙
- 사실 기반/운영 중심으로 기록
- 추정 날짜는 `(추정)` 표기
