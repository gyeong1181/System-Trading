# 3.0 초보자용 사용 설명서

## 이 버전은 어떤 봇인가

3.0은 `여러 종목을 각각 따로 관리할 수 있는 운영형 자동매매 봇`입니다.

- 기본 시작 심볼: `BTC-USDT-SWAP`
- 지원 심볼 확인 결과:
  - `BTC`
  - `XAU`
  - `XAG`
  - `GOOGL`
  - `NVDA`
  - `QQQ`
  - `SPY`
  - `TSLA`

쉽게 말하면:

- 2.0이 `한 종목 중심 봇`이라면
- 3.0은 `종목별로 따로 굴리는 멀티 계정판 느낌`입니다.

## 사용자가 체감하는 핵심 특징

- 종목을 여러 개 선택할 수 있습니다.
- 종목마다 seed를 따로 배분할 수 있습니다.
- 종목마다 설정을 따로 둘 수 있습니다.
- 종목마다 일시정지/재시작 개념이 있습니다.
- 내부적으로 종목별 매매 루프가 따로 돌아갑니다.

초보자 입장에서는:

- 더 강력하지만
- 한 번에 이해해야 할 요소가 많아졌다고 보면 됩니다.

## 대략 어떻게 동작하나

3.0의 흐름은 아래처럼 이해하면 쉽습니다.

1. 텔레그램에서 거래할 종목들을 고릅니다.
2. 종목마다 seed를 나눠 넣습니다.
3. 종목마다 레버리지, 손실 한도, 진입 성향 등을 설정합니다.
4. 각 종목별 상태 객체가 만들어집니다.
5. 종목마다 별도 매매 루프가 돌아갑니다.
6. 각 루프가 자기 종목 데이터만 보고 진입/청산을 판단합니다.

즉, `하나의 큰 봇`처럼 보이지만, 안에서는 `작은 봇 여러 개`가 함께 돌아가는 구조입니다.

## 사용자가 주로 만지는 설정

3.0은 공통 설정 하나만 보는 방식이 아니라, `종목별 설정`이 중요합니다.

- 종목별 seed 배분
- 종목별 레버리지
- 종목별 손실 제한
- 종목별 방향 설정
- 종목별 추세 필터
- 종목별 TP 설정
- 종목별 피보나치 스왑 전략
- 종목별 volatility 관련 설정
- 종목별 yearly target 계열 설정

즉, 사용자는 `내 자금을 어떤 종목에 얼마씩 배분해서 각각 어떻게 굴릴지`를 정하는 운영자 역할에 더 가깝습니다.

## 3.0의 전략은 완전히 새롭나

사용자 관점에서 중요한 포인트는 이겁니다.

- 3.0이 완전히 새로운 지표 봇으로 바뀐 건 아닙니다.
- 핵심 판단 축은 여전히:
  - RSI
  - 볼린저밴드
  - 피보나치
  - 스왑 전략
  - 추세 필터

즉, `판단 로직의 뼈대`보다 `운영 구조`가 훨씬 크게 업그레이드된 버전입니다.

## 초보자 입장에서 장점

- 여러 종목을 한 서버에서 분산 운용할 수 있습니다.
- 종목별 리스크 분리가 됩니다.
- 한 종목을 멈춰도 다른 종목은 계속 돌릴 수 있습니다.
- 내부적으로 자동 복구 구조가 더 강해졌습니다.
- 운영 유연성이 2.0보다 훨씬 높습니다.

## 초보자 입장에서 어려운 점

- 설정할 것이 많습니다.
- 잘못하면 seed 배분이 꼬일 수 있습니다.
- 종목별 설정 차이를 계속 기억해야 합니다.
- "왜 이 종목만 안 들어갔지?" 같은 추적이 2.0보다 더 어렵습니다.

## 2.0과 비교하면 쉽게 이렇게 이해하면 된다

- 2.0: `한 명 직원이 한 종목만 맡는 구조`
- 3.0: `직원 여러 명이 종목별로 따로 맡는 구조`

그래서 3.0은:

- 더 바쁘고
- 더 유연하고
- 더 세밀하게 운영할 수 있지만
- 초보자에게는 더 복잡합니다.

## 어떤 사람이 3.0을 쓰기 좋나

- 자금을 종목별로 나눠 운용하고 싶은 사람
- BTC만이 아니라 금, 은, 주식형 심볼까지 같이 보고 싶은 사람
- 운영 경험이 어느 정도 있는 사람
- 단일 전략보다 포트폴리오형 운영을 원하는 사람

## 한 줄 요약

3.0은 `멀티 심볼 운영형 자동매매 시스템`입니다.
초보자에게는 2.0보다 복잡하지만, 실제 운영 능력은 훨씬 강한 버전입니다.
