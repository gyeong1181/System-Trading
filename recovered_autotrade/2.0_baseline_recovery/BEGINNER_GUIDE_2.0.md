# 2.0 초보자용 사용 설명서

## 이 버전은 어떤 봇인가

2.0은 `한 종목 중심 자동매매 봇`에 가깝습니다.

- 기본 거래 대상: `XAU-USDT-SWAP`
- 쉽게 말하면: `금(XAU) 선물` 자동매매 전용에 가까운 버전
- 운영 방식: 한 개의 메인 루프가 계속 돌면서 시세 확인 -> 판단 -> 주문 실행

즉, 사용자는 보통 `한 종목에 집중해서 자동매매`를 돌린다고 이해하면 됩니다.

## 사용자가 체감하는 핵심 특징

- 구조가 비교적 단순합니다.
- 설정도 한 세트만 관리하면 됩니다.
- 텔레그램 봇이 사실상 조작 화면 역할을 합니다.
- 종목을 여러 개 나눠서 따로 굴리는 개념은 거의 없습니다.

초보자 입장에서는:

- 여러 종목을 동시에 관리할 필요가 없고
- "일단 하나만 안정적으로 돌려보자"는 용도에 더 가깝습니다.

## 대략 어떻게 동작하나

이 버전의 흐름은 대체로 아래와 같습니다.

1. OKX API 키와 텔레그램 정보를 확인합니다.
2. 텔레그램에서 설정을 받습니다.
3. 차트 데이터를 가져옵니다.
4. RSI, 볼린저밴드, 피보나치 같은 조건을 계산합니다.
5. 진입 여부를 판단합니다.
6. 조건이 맞으면 롱 또는 숏 주문을 넣습니다.
7. 이 과정을 반복합니다.

## 사용자가 주로 만지는 설정

2.0에서는 보통 아래 같은 설정을 한 세트로 관리합니다.

- 진입 금액
- 레버리지
- 손실 제한
- 방향 설정
- 익절 설정
- 피보나치 스왑 전략
- 추세 필터 적용 여부

즉, `내 계정 전체를 어떤 방식으로 운용할지`를 한 번 정해두는 느낌입니다.

## 2.0이 잘 맞는 사람

- 자동매매를 처음 접하는 사람
- 여러 종목보다 한 종목만 명확하게 보고 싶은 사람
- 구조가 단순한 쪽을 선호하는 사람
- 텔레그램으로만 컨트롤해도 충분한 사람

## 초보자 입장에서 장점

- 이해가 쉽습니다.
- 실수할 설정 포인트가 상대적으로 적습니다.
- 한 종목 기준으로 결과를 보기 편합니다.
- 장애가 나더라도 원인을 추적하기가 3.0보다 쉽습니다.

## 초보자 입장에서 아쉬운 점

- 여러 종목 분산 운용이 약합니다.
- 종목별로 따로 seed를 배분하는 구조가 아닙니다.
- 한 종목이 멈추면 전체 흐름을 다시 봐야 합니다.
- 운영 유연성은 3.0보다 낮습니다.

초보자가 이해하고 다루기에는 3.0보다 단순한 버전입니다.
