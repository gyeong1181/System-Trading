## 📝 당신이 해야 할 일 (순서대로)

### 1단계: AWS EC2 인스턴스 생성 (약 10분)

1. **AWS 콘솔 접속**
   - https://console.aws.amazon.com
   - EC2 서비스 선택

2. **인스턴스 시작**
   - "인스턴스 시작" 클릭
   - **Amazon Linux 2023** 선택
   - t3.micro (무료) 또는 t3.small 선택
   - 새 키 페어 생성: `btc-trend-key` (다운로드 필수!)
   - 보안 그룹: SSH (포트 22) - 내 IP만 허용
   - "인스턴스 시작" 클릭

3. **퍼블릭 IP 복사**
   - 인스턴스 목록에서 퍼블릭 IPv4 주소 복사 (예: `54.123.45.67`)

---

### 2단계: SSH 접속 (Windows PowerShell)

```powershell
# 키 파일이 있는 폴더로 이동 (보통 Downloads)
cd C:\Users\YourName\Downloads

# 권한 설정 (처음 한 번만)
icacls btc-trend-key.pem /inheritance:r
icacls btc-trend-key.pem /grant:r "$env:USERNAME:R"

# SSH 접속 (YOUR_EC2_IP를 실제 IP로 변경)
ssh -i btc-trend-key.pem ec2-user@YOUR_EC2_IP
```

접속 성공 시 `ec2-user@ip-xxx-xxx-xxx-xxx:~$` 프롬프트가 나타납니다.

---

### 3단계: 서버 초기 설정

EC2 서버에서 실행:

```bash
# 시스템 업데이트
sudo dnf update -y

# 필수 패키지 설치
sudo dnf install -y python3 python3-pip python3-venv unzip git
```

---

### 4단계: 코드 업로드

#### 방법 A: SCP로 파일 전송 (Windows PowerShell - 새 창 열기)

```powershell
# 프로젝트 폴더로 이동
cd "D:\코딩\자동매매\AI 자동매매 제작 프로젝트\BTC_trend_follow"

# 모든 Python 파일 전송
scp -i C:\Users\YourName\Downloads\btc-trend-key.pem *.py ubuntu@YOUR_EC2_IP:/tmp/

# 기타 파일 전송
scp -i C:\Users\YourName\Downloads\btc-trend-key.pem requirements.txt ubuntu@YOUR_EC2_IP:/tmp/
scp -i C:\Users\YourName\Downloads\btc-trend-key.pem BTCTrendFollower.service ubuntu@YOUR_EC2_IP:/tmp/
scp -i C:\Users\YourName\Downloads\btc-trend-key.pem deploy.sh ubuntu@YOUR_EC2_IP:/tmp/
```

#### EC2 서버에서 파일 정리

```bash
# 작업 디렉토리 생성
sudo mkdir -p /opt/btc_trend_follow
sudo chown ec2-user:ec2-user /opt/btc_trend_follow

# 파일 이동
mv /tmp/*.py /opt/btc_trend_follow/
mv /tmp/requirements.txt /opt/btc_trend_follow/
mv /tmp/BTCTrendFollower.service /opt/btc_trend_follow/
mv /tmp/deploy.sh /opt/btc_trend_follow/

# 실행 권한 부여
chmod +x /opt/btc_trend_follow/deploy.sh
```

---

### 5단계: 자동 배포 스크립트 실행

```bash
cd /opt/btc_trend_follow
./deploy.sh
```

스크립트가 자동으로:
- Python 가상환경 생성
- 패키지 설치
- systemd 설정

---

### 6단계: 환경변수 설정

```bash
cd /opt/btc_trend_follow
nano .env
```

**최소 설정 (페이퍼 모드 - 가짜 돈으로 테스트):**
```
BTC_TREND_PAPER_MODE=true
BTC_TREND_SYMBOL=BTCUSDT
BTC_TREND_INTERVAL=4h
```

저장: `Ctrl + O` → Enter → `Ctrl + X`

---

### 7단계: 테스트 실행

```bash
cd /opt/btc_trend_follow
source .venv/bin/activate

# 백테스트 실행 (400개 캔들)
python btc_trend_follow.py --paper --paper-bars 400
```

정상 작동하면 거래 로그가 출력됩니다.

**중단**: `Ctrl + C`

---

### 8단계: 실시간 모드 테스트

```bash
# 실시간 WebSocket 연결 테스트 (가짜 돈)
python btc_trend_follow.py --live --paper
```

"Connected to Binance btcusdt stream" 메시지가 보이면 성공!

**중단**: `Ctrl + C`

---

### 9단계: 24시간 자동 실행 설정

```bash
# systemd 서비스 시작
sudo systemctl enable BTCTrendFollower
sudo systemctl start BTCTrendFollower

# 상태 확인
sudo systemctl status BTCTrendFollower
```

**정상 작동 확인:**
- `Active: active (running)` 메시지 확인
- 로그 확인: `journalctl -u BTCTrendFollower -f`

## ⚠️ 실거래 전 주의사항

1. **충분한 테스트**: 최소 1주일 이상 페이퍼 모드로 테스트
2. **API 키 확인**: Binance Futures API 키가 올바른지 확인
3. **레버리지 확인**: `.env`에서 `BTC_TREND_LEVERAGE` 값 확인
4. **리스크 확인**: `BTC_TREND_RISK_PCT` 값이 적절한지 확인 (기본 1.0%)

실거래 모드로 전환:
```bash
nano /opt/btc_trend_follow/.env
# BTC_TREND_PAPER_MODE=false 추가
# BINANCE_API_KEY=실제키 추가
# BINANCE_API_SECRET=실제시크릿 추가
sudo systemctl restart BTCTrendFollower
```
