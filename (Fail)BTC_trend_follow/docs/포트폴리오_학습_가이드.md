## 🎯 포트폴리오 하이라이트 기술

### 1. **AWS S3 (Simple Storage Service)** ⭐⭐⭐

**이 프로젝트에서의 역할:**
- 거래 로그 CSV 파일 자동 백업
- 자산 곡선 데이터 영구 저장
- 날짜별 폴더 구조로 데이터 관리

**학습해야 할 내용:**

#### 초급 (이해 수준)
- ✅ S3 버킷 생성 방법
- ✅ 파일 업로드/다운로드 방법
- ✅ IAM 권한 설정 (버킷 접근 권한)
- ✅ `storage.py` 코드가 어떻게 S3에 업로드하는지 이해

**학습 자료:**
- AWS 공식 문서: "S3 시작하기"
- 실습: 버킷 만들기 → 파일 업로드 → 다운로드

#### 중급 (직접 구현 수준)
- ✅ boto3 라이브러리 사용법
- ✅ S3 버킷 정책 작성
- ✅ 수명 주기 정책 (Lifecycle Policy) 설정
- ✅ 버전 관리 (Versioning) 이해

**학습 자료:**
- `storage.py` 코드 분석
- boto3 공식 문서
- AWS S3 실습 강의

#### 고급 (설계 수준)
- ✅ 데이터 레이크 아키텍처 설계
- ✅ S3 + Athena + Glue 연동
- ✅ 비용 최적화 전략

**포트폴리오 어필 포인트:**
> "거래 데이터를 S3에 자동 백업하여 데이터 레이크를 구축하고, 향후 분석을 위한 기반을 마련했습니다."

### 2. **CI/CD (Continuous Integration/Continuous Deployment)** ⭐⭐⭐

**이 프로젝트에서의 역할:**
- GitHub Actions를 통한 자동 배포
- 코드 푸시 시 자동으로 서버에 반영

**학습해야 할 내용:**

#### 초급 (이해 수준)
- ✅ CI/CD의 개념 (왜 필요한가?)
- ✅ GitHub Actions 기본 사용법
- ✅ 워크플로우 파일 구조 이해
- ✅ `.github/workflows/deploy.yml` 코드 이해

**학습 자료:**
- GitHub Actions 공식 문서
- "CI/CD란 무엇인가?" 블로그 글
- 간단한 워크플로우 만들기 실습

#### 중급 (직접 구현 수준)
- ✅ GitHub Secrets 관리
- ✅ 여러 단계(Step)로 구성된 워크플로우 작성
- ✅ 조건부 실행 (특정 브랜치만 배포)
- ✅ 배포 실패 시 롤백 전략

**학습 자료:**
- GitHub Actions 고급 기능
- 다른 프로젝트의 CI/CD 파이프라인 분석
- 실습: 테스트 → 빌드 → 배포 파이프라인 만들기

#### 고급 (설계 수준)
- ✅ Blue-Green 배포 전략
- ✅ Canary 배포
- ✅ 자동화된 테스트 통합
- ✅ 여러 환경(Dev/Staging/Prod) 관리

**포트폴리오 어필 포인트:**
> "GitHub Actions를 활용하여 코드 푸시 시 자동으로 AWS EC2에 배포하는 CI/CD 파이프라인을 구축했습니다. 이를 통해 배포 시간을 90% 단축했습니다."
