# 로드맵

## MVP 목표
- 공개 채용 공고 2~3개 소스 수집
- 공개 기업 뉴스/변화 신호 1~2개 소스 수집
- 정규화, 중복 제거, 점수화
- 승인 기반 운영 UI
- Telegram 일일 다이제스트 발송

## 구현 순서
1. 프로젝트 골격과 설정, DB 모델을 만든다.
2. Greenhouse 채용 수집기와 공식 블로그/뉴스 HTML 수집기를 붙인다.
3. 중복 제거 해시와 규칙 기반 점수화를 적용한다.
4. 구조화 요약과 승인 대기열을 생성한다.
5. FastAPI + Jinja 관리 UI에서 승인/거절/미리보기를 제공한다.
6. Telegram 다이제스트 발송과 발송 로그를 남긴다.
7. pytest로 핵심 흐름을 검증한다.

## 다음 단계

- 요약기를 외부 LLM 제공자와 선택 가능하게 확장
- 승인 기준에 태그/우선순위 필터 추가
- 운영자용 일괄 승인/거절 액션 추가
