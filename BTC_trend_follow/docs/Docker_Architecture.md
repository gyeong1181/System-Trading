## 🔄 데이터 흐름 설명

```
Binance WebSocket → exchange.py → strategy.py → main.py
                                              ↓
                                    거래 실행 결정
                                              ↓
                          ┌───────────────────┴───────────────────┐
                          │                                       │
                          ▼                                       ▼
                    notifier.py                            exchange.py
                    (Telegram 알림)                        (실제 거래)
                          │                                       │
                          ▼                                       ▼
```

### 2. **로그 및 백업 흐름**
```
모든 이벤트 발생
      ↓

      ↓

      ↓
storage.py (S3 백업)
      ↓
S3 Bucket (CSV 파일 저장)
```

## 📦 각 구성 요소 역할

### 🐳 **Docker Container**
- **역할**: 자동매매 봇을 격리된 환경에서 실행
- **장점**: 
  - 서버 환경과 독립적으로 실행
  - 쉽게 배포 및 관리
  - 재시작 시 자동 복구

### 📝 **main.py**
- **역할**: 프로그램 시작점, 전체 흐름 제어
- **기능**: 
  - 환경변수 로드
  - 전략 초기화
  - 거래소 연결
  - 무한 루프 실행

### 🎯 **strategy.py**
- **역할**: 거래 전략 로직 (EMA, ADX 등)
- **기능**:
  - 캔들 데이터 분석
  - 매수/매도 신호 생성
  - 포지션 관리

### 💱 **exchange.py**
- **역할**: Binance API와 통신
- **기능**:
  - WebSocket 연결 (실시간 데이터)
  - REST API 호출 (주문 실행)
  - 포지션 관리

### 📢 **notifier.py**
- **역할**: Telegram으로 알림 전송
- **기능**:
  - 매수/매도 알림
  - 손익 알림
  - 에러 알림

### 💾 **storage.py**
- **역할**: S3에 데이터 백업
- **기능**:
  - 거래 로그 CSV → S3 업로드
  - 자산 곡선 CSV → S3 업로드
  - 주기적 백업 (예: 매일)

### 📊 **logger.py**
- **역할**: CloudWatch에 로그 전송
- **기능**:
  - 모든 로그를 CloudWatch로 전송
  - 로그 레벨 관리 (INFO, ERROR 등)
  - 실시간 모니터링 가능

## 🚀 실행 흐름

1. **EC2 서버 시작** → Docker 자동 시작
2. **Docker Container 시작** → main.py 실행
3. **환경변수 로드** → .env 파일 읽기
4. **Binance 연결** → WebSocket 연결
5. **전략 실행** → 4시간마다 신호 확인
6. **알림 전송** → Telegram으로 알림
7. **로그 저장** → CloudWatch + S3

## 💡 초심자를 위한 핵심 개념

### Docker란?
- **비유**: 가상의 상자 안에 프로그램을 넣어서 실행
- **장점**: 서버 환경이 바뀌어도 똑같이 작동
- **예시**: Windows에서 만든 프로그램을 Linux에서도 똑같이 실행

### CloudWatch란?
- **비유**: AWS의 로그 저장소
- **장점**: 모든 로그를 한 곳에서 확인 가능
- **예시**: 프로그램이 무슨 일을 했는지 기록

### S3란?
- **비유**: AWS의 파일 저장소 (구글 드라이브 같은 것)
- **장점**: 데이터를 안전하게 백업
- **예시**: 거래 기록을 영구 보관

### Telegram Bot이란?
- **비유**: 카카오톡 봇 같은 것
- **장점**: 스마트폰으로 실시간 알림 받기
- **예시**: 매수했을 때 휴대폰으로 알림

## 📈 확장 가능성

이 아키텍처는 나중에 쉽게 확장할 수 있습니다:

- **여러 전략 추가**: strategy.py를 여러 개 만들어서 동시 실행
- **다른 거래소 추가**: exchange.py를 확장해서 다른 거래소도 지원
- **알림 채널 추가**: Slack, Discord 등 추가 가능
- **데이터 분석**: S3 데이터를 분석해서 대시보드 만들기
