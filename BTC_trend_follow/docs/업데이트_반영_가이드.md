# 🔄 업데이트 반영 가이드

코드 수정 후 AWS 서버와 GitHub에 반영하는 방법입니다.

---

## 📋 두 가지 방법

### 방법 1: GitHub Actions 자동 배포 (권장) ⭐
- 코드 푸시만 하면 자동 배포
- 설정이 완료되어 있으면 이 방법 사용

### 방법 2: 수동 배포
- GitHub Actions가 없거나 문제가 있을 때 사용

---

## 🚀 방법 1: GitHub Actions 자동 배포

### 1단계: 로컬에서 코드 수정

```bash
# 프로젝트 폴더로 이동
cd "D:\코딩\자동매매\AI 자동매매 제작 프로젝트\BTC_trend_follow"

# 파일 수정 (예: main.py, exchange.py 등)
# VS Code나 에디터로 수정
```

### 2단계: Git에 커밋 및 푸시

```bash
# 변경사항 확인
git status

# 모든 변경사항 추가
git add .

# 커밋 (변경 내용 설명)
git commit -m "Telegram 알림 기능 추가"

# GitHub에 푸시
git push origin main
```

### 3단계: 자동 배포 확인

1. **GitHub에서 확인**
   - GitHub 저장소 → **Actions** 탭 클릭
   - "Deploy to AWS EC2" 워크플로우 실행 중 확인
   - ✅ 초록색 체크 = 성공
   - ❌ 빨간색 X = 실패 (로그 확인)

2. **EC2에서 확인**
   ```bash
   # SSH 접속
   ssh -i your-key.pem ec2-user@YOUR_EC2_IP
   
   # Docker 상태 확인
   cd /opt/btc_trend_follow
   docker-compose ps
   docker-compose logs --tail=50
   ```

**완료!** 자동으로 배포되었습니다.

---

## 🔧 방법 2: 수동 배포

### 1단계: GitHub에 푸시 (코드 백업)

```bash
# 변경사항 커밋
git add .
git commit -m "업데이트 내용 설명"
git push origin main
```

### 2단계: EC2에 파일 전송 (FileZilla)

1. **FileZilla 실행**
2. **연결 설정**
   - 호스트: `sftp://YOUR_EC2_IP`
   - 사용자명: `ec2-user`
   - 키 파일: `.pem` 파일 선택

3. **파일 전송**
   - 왼쪽(로컬): 수정한 파일 선택
   - 오른쪽(서버): `/opt/btc_trend_follow`로 드래그 앤 드롭

### 3단계: EC2에서 Docker 재시작

```bash
# SSH 접속
ssh -i your-key.pem ec2-user@YOUR_EC2_IP

# 작업 디렉토리로 이동
cd /opt/btc_trend_follow

# Docker 재빌드 및 재시작
docker-compose down
docker-compose build
docker-compose up -d

# 로그 확인
docker-compose logs -f
```

**완료!** 수동 배포가 완료되었습니다.

## 🆘 문제 해결

### 문제 1: GitHub Actions가 실행되지 않음

**확인 사항:**
1. `.github/workflows/deploy.yml` 파일이 있는지 확인
2. `main` 브랜치에 푸시했는지 확인
3. GitHub Secrets가 설정되어 있는지 확인

**해결:**
- [GitHub Actions 설정 가이드](GitHub_Actions_설정_가이드.md) 참고

### 문제 2: 배포는 성공했지만 서비스가 작동 안 함

**확인:**
```bash
# Docker 로그 확인
docker-compose logs -f

# 컨테이너 상태 확인
docker-compose ps

# 수동 실행 테스트
docker-compose run --rm btc-trend-bot python main.py
```

### 문제 3: 파일이 업데이트되지 않음

**확인:**
```bash
# 파일 수정 시간 확인
ls -la /opt/btc_trend_follow/*.py

# 파일 내용 확인
cat /opt/btc_trend_follow/main.py | head -20
```
